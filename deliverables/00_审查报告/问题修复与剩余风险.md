# 问题修复与剩余风险

## 已修复

1. `/materials` 页面原本主要由服务端渲染，浏览器不一定产生可在 Fetch/XHR 中截图的材料列表请求。已在 `app/static/app.js` 增加页面加载后 `fetch('/api/materials')`，并用响应刷新列表。
2. 材料列表缺少可见搜索入口。已在 `app/templates/materials.html` 增加搜索框，`app/db.py` 与 `/api/materials?q=...` 支持按标题/原文件名搜索，同时仍强制使用会话班级过滤。
3. 自动测试中 Windows 无符号链接权限导致路径越界 symlink 用例失败。已改为无权限时 `pytest.skip`，其余越界场景继续执行。
4. 新增 `scripts/browser_f12_validation.cjs`，可复现真实 Chrome 浏览器网络验收。
5. 交付证据已运行 `scripts/sanitize_evidence.py` 脱敏 Cookie、CSRF 与密码值。
6. 第 2 课交付副本中的 `tasks.md` 已保持全部 `[ ]`，避免把后续实现状态伪装成第 2 课当堂产物。

## 剩余风险

1. Docker Desktop/Engine 未运行，`docker compose up --build -d` 未能启动容器，因此容器构建和 down/up 持久化仍需在 Docker 可用环境复验。
2. 本地 HTTP 演示环境 `COOKIE_SECURE=0`，正式 HTTPS 部署应设置 `COOKIE_SECURE=1`，并进一步补充 CSRF/HTTPS/日志保密等生产配置。
3. Flask signed cookie 会话是客户端持有、服务端签名校验的会话，不是服务器数据库 session；README 已按实际实现说明。
4. 浏览器证据使用 headless Chrome 自动化，不替代你本人 F12 截图；它只证明真实浏览器会发出相同请求。
5. `tmp/pw` 是为本次浏览器验收临时安装的 Playwright 包；不属于业务源码交付。
