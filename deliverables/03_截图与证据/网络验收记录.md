# 网络验收记录

基础地址：`http://127.0.0.1:8080`。运行方式：本地 Flask 服务 `python scripts\start_local.py`。Docker Compose 因 Docker Engine 未运行未完成启动。

| 操作 | 请求 | 预期 | 实际 | 证据 |
|---|---|---|---|---|
| 匿名健康检查 | `GET /health` | 200 JSON | 200 `{"database":"ok","status":"ok"}` | `http-evidence/07-health-response.http` |
| 教师登录 | `POST /login` | 302 到 `/materials`，Set-Cookie | 302，`Location: /materials`，`campusclaw_session` HttpOnly/Lax | `browser-evidence/browser-network-validation.json` |
| 登录后材料 XHR | `GET /api/materials` | 200，携 Cookie，仅 A 班 | 200，resource_type 为 fetch，Request Headers 有 Cookie | 同上 |
| 教师上传 | `POST /api/materials/upload` | 201 JSON | 201，multipart/form-data，页面刷新后列表可见 | 同上 |
| 本班下载 | `GET /api/materials/<id>/download` | 200 attachment | 200，`Content-Type: application/octet-stream` | 同上及 `extra-http-evidence` |
| 未登录下载 | `GET /api/materials/<id>/download` | 401 | 401 `{"error":"请先登录"}` | 同上 |
| 学生直接上传 | `POST /api/materials/upload` | 403 | 403 `学生仅可查看本班材料...` | 同上 |
| 跨班下载 | `GET /api/materials/3/download` | 404 | 404 `材料不存在或不可访问` | 同上 |
| 非法类型 | `POST /api/materials/upload` `.pdf/.docx` | 400 | 400 | `extra-http-evidence` |
