# F12 手动补拍指南

## 先决条件

运行：

```powershell
python scripts\configure.py
python scripts\start_local.py
```

打开：`http://127.0.0.1:8080/login`。

演示账号：

- 教师：`teacher_a` / `Campus@2026`
- 学生：`student_a1` / `Campus@2026`
- B 班学生：`student_b1` / `Campus@2026`

截图时遮盖：密码值、`campusclaw_session` Cookie 值、`csrf_token` 值。

## 1 教师已登录首页

登录 `teacher_a`，进入 `/materials`。截图页面主体，保留左侧 `教师 A`、`班级 A`，中间材料列表，右侧 `上传教学材料` 表单。

## 2 登录 Payload

清空浏览器 Cookie 或用隐身窗口。打开 F12 -> Network -> All 或 Doc。提交登录表单。选中 `login` 的 `POST` 请求，打开 Payload，截图 `username=teacher_a`、`password=[遮盖]`、`csrf_token=[遮盖]`。

## 3 登录 Response 与 Headers

仍选中 `POST /login`。打开 Headers，截图：

- Request URL：`http://127.0.0.1:8080/login`
- Request Method：`POST`
- Status Code：`302`
- Response Headers：`Location: /materials`
- `Set-Cookie: campusclaw_session=[遮盖]; Expires=...; HttpOnly; Path=/; SameSite=Lax`

## 4 materials Fetch/XHR 请求

登录后停在 `/materials`，刷新页面。Network 选择 Fetch/XHR，选中 `materials` 请求，URL 应为 `GET http://127.0.0.1:8080/api/materials`。

Headers 截图：Request Headers 中应有 `Cookie: campusclaw_session=[遮盖]`。

Response 截图：JSON 中只应出现 `class_id: 1` 的 A 班材料，不应出现 `B 班 · 独立教学材料`。

## 5 下载权限

本班成功：教师登录后打开任意 A 班材料详情，点击 `下载原文件 ↓`。Network 选中 `download` 请求，截图 Status 200、`Content-Disposition: attachment`、`Content-Type: application/octet-stream`。

未登录失败：退出或隐身窗口直接打开 `http://127.0.0.1:8080/api/materials/1/download`，截图 401 JSON。

跨班失败：教师 A 登录后直接打开 `http://127.0.0.1:8080/api/materials/3/download`，截图 404 JSON，响应不含 B 班标题或正文。

## 6 上传流程

教师登录 `/materials`，Network 选 Fetch/XHR。选择本地 `.txt` 或 `.md` 文件，标题填 `F12上传验收材料`，点击 `上传并入库`。选中 `upload` 请求：

- Payload：`multipart/form-data`，字段 `csrf_token`、`title`、`file`，文件名可见。
- Response Headers/Response：Status 201，JSON 类似 `{"message":"材料已上传并写入知识库","material_id":...,"class_id":1}`。
- 随后选中新的 `GET /api/materials`，Response 中应出现新标题。

学生 403：退出，用 `student_a1` 登录。页面不显示上传表单。可在 Console 执行带当前 CSRF 的直接请求较麻烦，建议使用证据文件中的 `scripts/browser_f12_validation.cjs` 或 Postman/curl 复现；若坚持 F12，可先在 `/api/me` Response 复制 `csrf_token`，再 Console 发 `fetch('/api/materials/upload',{method:'POST',body:formData})`，应返回 403。截图时遮盖 token。

非法类型：教师登录后选择 `.pdf` 或 `.docx`，上传请求应返回 400。

## 7 `/health` 与部署证据

地址栏打开 `http://127.0.0.1:8080/health`，截图 200 JSON。Docker 可用时再运行：

```powershell
docker compose config
docker compose up --build -d
docker compose ps
```

截图 Compose 配置和容器状态。本项目没有 Nginx，除非你自己另加代理，否则不需要 Nginx 配置截图。
