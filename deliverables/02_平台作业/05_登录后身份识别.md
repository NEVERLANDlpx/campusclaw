# 05 登录后身份识别

登录成功后，Flask 设置签名 Cookie，Cookie 名为 `campusclaw_session`。后续同源请求自动携带该 Cookie；服务端校验签名、过期时间和 `auth_version`，再从数据库读取当前用户、角色和班级。

Cookie 属性实测：

- 名称：`campusclaw_session`
- `HttpOnly`
- `SameSite=Lax`
- `Path=/`
- 登录后有 `Expires`
- 本地 HTTP 下没有 `Secure`，正式 HTTPS 部署应设 `COOKIE_SECURE=1`

浏览器证据显示，登录后 `GET /api/materials` 的 Request Headers 中有 `Cookie: campusclaw_session=[REDACTED]`，Response 只含 `class_id=1` 的 A 班材料。前端 JS 不读取 Cookie。

证据：`deliverables/03_截图与证据/browser-evidence/browser-network-validation.json`。
