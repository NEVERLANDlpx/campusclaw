# 04 文件上传逻辑及类型测试

上传接口：`POST /api/materials/upload`，页面表单位于 `/materials`，字段为 `csrf_token`、`title`、`file`。

流程：教师会话认证 -> 角色检查 -> CSRF 校验 -> 扩展名与大小检查 -> UTF-8 解析 -> 安全文件名和班级目录落盘 -> 同事务写 `materials`、`knowledge_entries`、`lectures` -> 返回 201 -> 页面刷新并由浏览器 fetch `/api/materials` 更新列表。

实际支持：`.txt`、`.md`，大小上限 2 MiB，总请求上限 3 MiB，内容必须为非空 UTF-8 文本且不能含二进制控制字符。

实测：

- 教师上传 `.txt`：浏览器 multipart 请求 201，上传后列表刷新可见。
- 教师上传 `.md`：HTTP 采集 201，下载字节一致。
- `.pdf`、`.docx`、`.xlsx`、`.png`、`.csv`、`.json`、`.exe`、`.txt.exe`：400，无业务脏数据。
- 空文件、无效 UTF-8、二进制内容、超限文件：pytest 覆盖失败无脏数据。
- 学生直接 POST 上传：403。

证据：`tests/test_acceptance.py`、`deliverables/03_截图与证据/browser-evidence/browser-network-validation.json`、`deliverables/03_截图与证据/extra-http-evidence/`。
